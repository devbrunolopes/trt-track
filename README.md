# TRT TRACK v1.15.0

Aplicativo PWA para registro e organização pessoal de aplicações, com calendário, planos, histórico, rodízio de locais e backup local.

## Identidade
- Nome: TRT TRACK
- Tema exclusivo escuro em azul-marinho e verde-limão
- Interface sem publicidade ou banners externos

## Substâncias padrão
- Deposteron — 200 mg/2 mL — EMS
- Durateston — 250 mg/1 mL — ASPEN
- Mounjaro — 5 mg/0,5 mL — Eli Lilly
- Mounjaro — 7,5 mg/0,5 mL — Eli Lilly
- Mounjaro — 10 mg/0,5 mL — Eli Lilly
- Mounjaro — 12,5 mg/0,5 mL — Eli Lilly
- Mounjaro — 15 mg/0,5 mL — Eli Lilly

As concentrações internas são armazenadas em mg/mL para manter os cálculos de dose existentes. Os volumes de apresentação são usados como valor inicial nos formulários.

- `npm install`
- `npm run dev`
